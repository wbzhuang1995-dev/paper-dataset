# Baseline Prompts

This directory provides the task-adapted prompt texts for the “-style” baseline implementations reported in Table 7 of the manuscript.

Included baselines:

- Agents-style
- AutoAgents-style
- MetaGPT-style
- AutoTRIZ-style
- HermesAgent 0.12-style
- OpenClaw 5.7-style

For each baseline:

- `*_style.md` contains the prompt texts used in the comparative implementation.
- `*_style_notes.md` provides brief information on the framework basis, source mapping, task adaptation, and evaluation controls.

All baseline implementations were adapted to the same rehabilitation assistive device configuration task and the common If–Then–Unless–Verify output format used in the comparative evaluation.
